PROJECT SPECIFICATION PROMPT

Goal: Implement and display a PropertySheet table that dynamically reflects and controls the properties of selected shapes on a canvas application.



 PROPERTY SHEET REQUIREMENTS

Table to show in presentation (PropertySheet folder):



The PropertySheet should display the following properties:




Property

Description







Width

Width of the shape




Height

Height of the shape




Thickness of the Line

Border thickness of the shape




Fill Color

Fill color of the shape




Current Shape

Type of shape selected




X Location

X-coordinate of the shape




Y Location

Y-coordinate of the shape










If no shape is selected → all fields should be null.




If the shape is manually modified, the values in the PropertySheet should update automatically.




If a value is edited in the PropertySheet, the shape should update accordingly.




When a shape is drawn on the canvas, its information should be automatically reflected in the PropertySheet.




All of the information in the gallery should be displayed in one row only.
